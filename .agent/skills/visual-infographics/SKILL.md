# Visual Infographics Skill

## Purpose
Create judge-friendly, data-driven disaster-response infographics in the React dashboard.

## Rules
- Visualize real application state, not invented metrics.
- Make risk, severity, affected population, trends, alert propagation, evacuation, and safe navigation immediately understandable.
- Use clear hierarchy and concise labels.
- Show data freshness/source: LIVE, HISTORICAL, or SIMULATED.
- Use accessible contrast, readable typography, and non-color cues for severity.
- Keep responsive layouts usable on desktop and mobile.
- Prefer reusable visualization components.
- Avoid decorative charts that do not communicate decisions.

## SIH visuals
Risk gauge, hazard trend, affected-area summary, alert timeline, AI decision flow, evacuation status, safe-route summary, and system architecture/data flow.
