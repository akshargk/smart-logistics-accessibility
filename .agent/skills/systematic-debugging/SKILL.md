# Systematic Debugging Skill

When a bug appears:
1. Reproduce it reliably.
2. Capture the exact error and affected path.
3. Form hypotheses from evidence.
4. Trace the full data/control flow.
5. Make the smallest justified fix.
6. Add a regression test.
7. Re-run focused tests, then the broader suite.
8. Verify the original failure is actually gone.

Do not randomly change multiple files or declare success from a build alone.
