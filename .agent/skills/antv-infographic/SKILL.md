# AntV Infographic Skill

## Purpose
Use AntV Infographic in the existing React/Vite frontend for structured visual explanations.

## Rules
- Treat AntV Infographic as a frontend library, not as a backend skill.
- Install it according to its current official documentation; do not copy its source repository into `.agent/skills`.
- Integrate components under the existing `src/` structure.
- Do not create a second frontend project.
- Feed charts/infographics from real API state.
- Clearly label simulated/demo data.
- Use it for decision-oriented visuals such as disaster-response flow, AI risk pipeline, alert propagation, evacuation workflow, and system architecture.
- Keep text concise and readable.
- Ensure responsive and accessible presentation.
- Test rendering with realistic empty/loading/error states.

## SIH principle
Every infographic should help a judge understand either what happened, why the system decided it, or what action the user should take.
