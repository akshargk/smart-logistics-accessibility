# Verification Before Completion Skill

Never claim a task is complete from assumption.

Before reporting completion:
- Run relevant tests.
- Run lint/type/build checks when applicable.
- Verify migrations if schema changed.
- Verify API responses and error cases.
- Verify UI behavior when user-facing.
- Verify WebSocket behavior for real-time changes.
- Confirm the requested files/features actually exist.
- Report failures honestly.
